For some of these problems there exist 'efficient' solutions such as [greedy algorithms](Search%20Spaces.md#A%20more%20intelligent%20approach), [divide and conquer](Sorting.md#Merge%20Sort), [dynamic programming](Dynamic%20Programming.md), etc. But for other problems, there are less efficient, but still good algorithms, such as [backtracking](Search%20Spaces.md#Backtracking%20Implementations) or [branch and bound](Search%20Spaces.md#Branch%20and%20Bound%20Implementations). ##### SAT
*SAT*, short for satisfiability is a decision problem where, given a number of logical statements, operating on a fixed number of binary variables. The question is, is there a combination of true/false variables such that all the logical statements evaluate to true. Alternately, MAX-SAT asks what the maximum number of logical statements is that can be true at once and what combination of binary variables will get you there.
### NP-Hard Problems
SAT is just one of the more famous optimisation by simply trying all the guesses that such a Turing machine could make and evaluating them all.

We say that any decision problem that can be solved in polynomial time by a problems, but SAT and others like it such as [TSP](Search%20Spaces.md#Optimising%20the%20Travelling%20Salesman%20Problem), [graph colouring](../Datastructures/Graph%20Theory.md#Graph%20Colouring), scheduling problems, bin-packing or quadratic integer problems. These problems all belong to a class of problems called *NP-hard*. Other problems solved by the 'efficient' methods listed above are considered to be *easy*, as they can be solved in polynomial time.
The question is: can we solve *NP-hard* problems in polynomial time? And the answer: **maybe**. We don't know and nobody has discovered such an algorithm. In fact, if somebody did, then we would be able to solve *every* NP-hard problem in polynomial time.
##### Deriving P
A decision problem is one such that it can be answered by either 'true' or 'false'. Any decision problem that can be run in polynomial time $n^k$ on a normal computer (Turing machine) is said to be in class $P$.
##### Turing Machines
A *Turing machine* is a type of imaginary dumb computer that has a tape of arbitrary length, filled with 1's and 0's. It can move its 'head' up and down the tape, read from the tape and write to the tape. The Turing machine contains some logic as to its actions given what it reads from the tape. Although it may solve problems slower than 'real' computers, usually taking $O(n)$ algorithms to be $O(n^2)$, due to its lack of random memory access, a Turing machine is capable of solving any problem that any other computer can.

A *non-deterministic Turing machine* is a magical Turing machine that can guess the answer to the problem, with a standard Turing machine bolted on that can verify the solution to the problem. We also assume that a non-deterministic Turing machine will always guess the right answer on the first try. While is is possible to simulate a normal Turing machine in polynomial time, nobody has ever solved a non-deterministic Turing machine in anything better than *exponential time* by simply trying all the guesses that such a Turing machine could make and evaluating them all.
##### Deriving NP
We say that any decision problem that can be solved in polynomial time by a *non-deterministic Turing machine* exists in a set $NP$. By inspection, we can also see that if a problem exists in $P$, it must also be in $NP$. Thus $P \subseteq NP$. It is important to note that there are problems that are neither $P$ or $NP$. One such example of a problem would be 'Is this game of chess winnable by white?'.

To be mathematical, the for a problem to be in $NP$, the problem must be:
- A decision problem (have a true or false answer)
- Be describable by some polynomial sized string in the length of the input $n$
- Have solutions that are verifiable by a normal Turing machine in polynomial time.
For a solution to be verifiable, it is sufficient for the problem's solution to have a 'witness', which is in general, a solution that can be checked in polynomial time. For example, for the travelling salesman problem, a suitable witness would be a tour through all the vertices we could travel and verify it satisfies the conditions.
##### NP-Complete
In 1971, it was shown that any NP problem could be represented using a SAT problem of polynomial size, run on a non-deterministic Turing machine. Such a problem is an example of an NP-complete problem: an NP-hard problem that can be transformed into any other NP-hard problem. Thus, by solving an NP-complete problem in polynomial time, all NP-hard problems can be solved in polynomial time. If there does exist a solution to an NP-complete problem that runs on a standard Turing machine, then we have an answer to the question of if $NP = P$, as the existence of such a solution implies that $NP = P$.
