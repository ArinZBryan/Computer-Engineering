### Definitions
**Data Structure**
A data structure is any of various methods of organising data items (as records) in a computer. More succinctly, a data structure is some container for data items. Generally, data structures have a clean interface (though not always) and are optimised for either performance or convenient access.
**Algorithm**
A sequence of unambiguous instructions for solving some problem. An algorithm is well-defined and generic and should have known performance characteristics
